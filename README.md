# Статический интерфейс «Ежедневник»

Простая одностраничная реализация веб-приложения для ведения списка дел. Проект создан для демонстрации навыков адаптивной верстки с использованием HTML5 и CSS3, а также базового взаимодействия с DOM с помощью нативного JavaScript (Vanilla JS).


## ✨ Основные возможности

* **Добавление задач**: Форма для ввода названия (обязательно) и описания (опционально) новой задачи.
* **Список задач**: Все добавленные задачи отображаются в виде наглядных карточек.
* **Удаление задач**: Каждую задачу можно удалить нажатием на соответствующую кнопку.
* **Адаптивный дизайн**: Интерфейс корректно отображается на устройствах с шириной экрана от 320px (мобильные) до 1920px (десктоп) благодаря подходу Mobile-First.
* **Интерактивность**: Взаимодействие с элементами реализовано на чистом JavaScript без использования внешних библиотек и фреймворков.

## 🛠️ Технологии

* **HTML5**: Семантическая разметка для структуры страницы.
* **CSS3**:
    * **Flexbox** и **Grid Layout** для построения адаптивных сеток.
    * **Media Queries** для адаптации стилей под разные разрешения экрана.
    * **CSS Variables** для удобного управления цветовой схемой и отступами.
* **JavaScript (ES6+)**:
    * Работа с DOM (создание, добавление и удаление элементов).
    * Обработка событий (`addEventListener`).
    * Делегирование событий для эффективного управления списком задач.

## 📂 Структура проекта

Репозиторий содержит три основных файла:

```
├── index.html   # Основной файл с HTML-разметкой страницы
├── style.css    # Файл со стилями для визуального оформления и адаптивности
└── script.js    # Файл с JavaScript-логикой приложения
```

* `index.html` — определяет структуру веб-страницы: шапку, форму добавления и контейнер для списка задач.
* `style.css` — отвечает за весь визуал. Стили организованы по принципу **Mobile-First**.
* `script.js` — "оживляет" страницу, реализуя логику добавления и удаления задач.
